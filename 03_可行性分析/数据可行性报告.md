# 数据可行性报告：打字 × PD 四库（2026-09-25 实测 + 文献双通道核查）

**总结论：绿灯，但为"小数据精细设计"路线。** 数据门槛全领域几乎最低（总体积 <300MB、零申请、直链下载），硬约束是金标准样本量小（118 人），应对方案已明确。

---

## 一、四库实测矩阵（链接全部亲手验证）

| 数据集 | 实测可得性 | 受试者 | 标签质量 | 体积 | 记录协议 |
|---|---|---|---|---|---|
| neuroQWERTY MIT-CSXPD | ✅ 新版 PhysioNet 页面 + AWS 双活（实测 200 OK） | 85 人（42 PD / 43 HC） | **临床金标准**（神经专科 + UPDRS-108 自带） | 7.3 MB | 物理键盘自由打字，完整 press/release 事件流（3ms 分辨率），每人平均仅 1.36 session |
| Tappy Keystroke | ✅ AWS 开放桶（实测解析了标签文件） | **227 人（PD 169 / 对照 55 / 单纯震颤 3）**——比文献流传的 57/103 多 | ⚠️ 自我报告（最弱）；确诊年份 1991–2017 | 89 MB | 家庭 Windows 电脑系统级钩子，数周至数月自然打字，只记左右手+键位（**无字符身份**），人均约 145 session，hold/flight/latency 直接给出 |
| TyPD | ✅ Zenodo 直链 365 kB（zenodo.org/records/2571623） | 33 人（18 PD / 15 HC） | **金标准**（UPDRS-III + Hoehn-Yahr 附表） | 365 kB | 手机自定义输入法抄写固定文本，含**压力通道**（其余库没有） |
| Online English | ✅ OSF 直链 125 MB（osf.io/ean63） | 230 人（100 PD / 130 HC） | 自我报告（在线招募问卷） | 125 MB | 浏览器抄写固定 Wikipedia 句子，人均 14.57 session |

四库受试者级总池约 **450–550 人**；其中**临床金标准子池仅 118 人**（MIT 85 + TyPD 33）。

## 二、CP 样本量核算（硬约束与应对）

- split conformal 稳定兑现 90% 覆盖，通行经验校准集需数百例；**"全金标准大校准"在本数据条件下做不到**。
- 应对（也是论文卖点）：
  1. 金标准小池（118 人）做**校准锚点**；
  2. **金标准→自报的迁移校准**分析（标签噪声 × 覆盖率的交互做成正式章节——Tripathi 的 0.81→0.64 掉点是现成动机）；
  3. Tappy 按 session 切分扩充有效样本，但统计单位锁死在"人"（防伪重复）；
  4. 预期管理：报告的覆盖 CI 会偏宽（第一篇 in-field 论文可接受）。

## 三、跨库调和的五个坑（已知解法，全部进预注册）

1. **协议不齐**：物理键盘（MIT/Tappy）vs 手机触屏（TyPD）vs 浏览器（OE）——压力通道弃用；
2. **粒度不一**：Tappy 无字符身份→二连键特征只能用 hold/flight/latency 三信号；
3. **session 结构悬殊**：人均 145（Tappy）vs 1.36（MIT）个 session——切分口径预注册固定（Francesconi 口径：固定文本 ≥20 字符/分、flight>3s 剔除；自由文本不清洗）；
4. **标签口径**：确诊 vs 自报分层评估（自报训练+确诊测试是文献标准做法）；
5. **清洗规则各家不一**：统一采用 Francesconi 2025 四信号口径。

## 四、文献基准（防止开题被问穿）

- 单库内现实预期：AUC 0.80–0.91（金标准库）；
- 跨库衰减是真实且已被量化的：Tappy→MIT 最好仅 0.666；固定→固定 0.89–0.91；
- **Adams 2017 的 AUC 1.00 是公认小样本过拟合，禁止写进开题当预期**；
- 性别不匹配：MIT 对照组女性多 17 个百分点——分组校准审计时注意。

## 五、工程注意事项

- 跨境下载实测仅约 5.6 KB/s（AWS S3），必须 `curl -C -` 断点续传或走小集群；总下载量 <300MB；
- 文件格式：MIT/neoQWERTY 为逐 session CSV（字符、hold、release、press 四列）；Tappy 为人×月 txt（Hand, HoldTime, Direction, LatencyTime, FlightTime 直接给出）；TyPD 为逐人文件夹+Excel 临床表；OE 为单个大 CSV；
- 官方代码：neuroQWERTY 自带 nqDataLoader.py + readme.ipynb；OE 自带 GitHub 仓库（neildhir/Parkinsons_typing_markers，Python 2/3 兼容需自查）；
- 数据版本：锁定各库当前发布版本号，记录下载日期与 SHA256（Tappy 提供 SHA256SUMS.txt）。
