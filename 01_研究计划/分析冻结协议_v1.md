## 1. Dataset（冻结）

| 项 | 冻结值 |
|---|---|
| 纳入 | 四库全量受试者，经 §3 清洗规则后保留者 |
| PD 定义 | MIT/TyPD：临床诊断字段（金标准）；Tappy/OE：自报字段（Parkinsons=True / diagnosis 自述） |
| HC 定义 | MIT/TyPD：临床对照字段；Tappy/OE：自报 False |
| 单纯震颤（Tappy，n≈3） | Tremors=True & Parkinsons=False → 主分析排除；敏感性分析分别计入 PD 与 HC 各复算一次 |
| OE H&Y 0 期自述 | 主分析保留（自报层入组定义）；敏感性分析剔除 |
| 每人取库 | 每受试者仅首次卒中/首次访视口径，同一人 session 绝不跨数据集分割 |
| 样本数口径 | **唯一权威 = W3 冻结队列表**（raw N → 排除 → eligible → PD/HC），不沿用任何引用论文的分析子集数字 |

## 2. Feature（冻结）

| 档 | 特征 | 适用库 |
|---|---|---|
| L1 | hold/flight/latency 的 mean/median/sd/p10/p90（无条件） | 四库全部（TyPD 上限） |
| L2 | L1 + 手别条件特征（左右手分层统计） | MIT/Tappy/OE |
| L3 | L2 + 字符二连键特征 | MIT/OE |
| 清洗 | 固定文本 flight>3s 剔除、<20 字符/分剔除；自由文本不清洗；digraph hold/latency ≤0 或 >10s 剔除；session 有效 digraph<100 剔除；person 有效 digraph<300 排除 | 全部 label-blind |
| 跨库降档 | 按目标库可用档位自动降档；**特征档位作为覆盖衰减的显式协变量记录** | — |

## 3. Model（冻结）

- **Primary：LightGBM**（梯度提升树，表格特征）
- **Secondary：逻辑回归**（复刻 Tripathi 掉点口径）
- 禁止：深度时序模型、任何新模型家族（scope discipline）
- 调参：仅源域内部 CV；**目标库对一切调优决策隔离**（Target datasets are never used for model selection）

## 4. CP（冻结）

- **Primary：split conformal**（二分类，score = 1 − 真类概率）
- Secondary/sensitivity：CV+（理论保证 1−2α，已标注）、weighted CP（探索性，密度比加权，权重截断+分布报告）、group-weighted CP（按设备/协议分组，remediation benchmark）
- 校准：源域受试者级分层切分；目标域重校准按预算梯度 0/5/10/20/30% 标注
- **不变量：One subject = one conformal observation**；人级分数 = 有效 session 分数中位数（worst-session 敏感性）

## 5. Evaluation（冻结）

| 层 | 指标 | 地位 |
|---|---|---|
| Primary family（预注册，Holm 内部校正，family-wise 0.10） | 3 个高功效方向 × α=0.10 × 总体覆盖 | 主结论 |
| 安全性诊断（**非形式保证**） | PD 类条件覆盖、HC 类条件覆盖 | 必报，不进 primary family |
| 效率 | 平均/中位集合大小、单例集比例 | 必报 |
| 部署效用 | 单例=自动通过 / 双例=人工复核 / 全集=系统拒绝 的比例 | 必报 |
| 判别力 | 受试者级 AUC（bootstrap CI） | 解释性辅助 |
| 三分类判定 | Compatible（CI 下界 ≥0.80）/ Incompatible（CI 上界 <0.90）/ Undetermined | **判定对象 = 观测覆盖与审计阈值的统计相容性，非真实失败断言** |
| 阈值定性 | 0.80 = pre-specified operational audit threshold，非临床安全阈值 | — |
| CI | 覆盖率用 Clopper-Pearson 精确二项；AUC 用分层 bootstrap | — |
| H1 检验 | 方向级 (ΔAUC, Δ总体覆盖, ΔPD覆盖) 描述性散点；**禁 12 方向相关性显著性检验** | — |

## 6. Adaptation（冻结）

| 补救 | 预算/配置 |
|---|---|
| 目标域重校准 | 0/5/10/20/30% 目标域标注梯度（**target calibration budget = 一级概念，恢复-代价表为正式结果**） |
| weighted CP | 密度比估计 + 权重截断 + 权重分布报告（探索性，预注册零预期） |
| group-weighted CP | 按设备/协议分组（benchmark 引用 EJS 2026） |
| 禁止新增 | 任何新 CP 变体、深度学习、domain adaptation、贝叶斯/集成 UQ、新数据集 |

## 7. 术语与声明（冻结）

- 三分类判定对象 = **观测覆盖与审计阈值的统计相容性**，非真实失败断言；
- 0.80 = pre-specified operational audit threshold；
- PD 类条件覆盖 = safety-oriented diagnostic endpoint，**非分布无关保证**（依据 arXiv:2607.18088）；
- 应力测试容差 ±5pp/±0.3 = 预设实用等价容差；结论限定"是否**足以复现**"，不主张因果识别；
- 结果无条件声明：Primary scientific outcomes are not conditioned on observing coverage degradation；
- 合并临床标注源池的"合并"仅指标签来源质量，不隐含成分数据集分布可交换。
